# 方案设计

失败归因优先使用可复现证据：执行异常、工具名和参数差异、知识工具是否被调用、JSON 格式、rubric 指标和最终回复依次判断；无法匹配时使用兜底分类，确保每个失败 case 都有原因。训练集仅用于候选生成，验证集独立执行 baseline 与 candidate 的完整评测，且按 case ID 比较，不按结果顺序比较。Gate 同时要求验证总分达到提升阈值、没有新增 hard fail、保护 case 与保护指标不退化、成本和耗时不超预算；训练提升但验证总分或通过率下降会触发过拟合拒绝。每次运行保存配置快照、prompt 哈希、四次评测、候选、逐 case delta 和规则结果；不保存密钥、认证头、环境变量或模型思考文本。只有真实模式且显式 `--apply`、优化成功、Gate 接受、源 hash 未变化时才允许写回。
